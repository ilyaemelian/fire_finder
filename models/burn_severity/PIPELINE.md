# BS: бустинг + U-Net — описание пайплайна

| файл | что |
|---|---|
| `unet_train.ipynb` | обучение U-Net на 224 обучающих чипах |
| `inference_new.py` | инференс: бустинг + U-Net → смесь → `submission.csv` |
| `models/` | все веса: 5 моделей первого прохода бустинга, модель второго прохода, U-Net, нормировка |
| `IDEAS.md` | почему U-Net и почему в паре с бустингом |
| `requirements.txt` | зависимости |

Обучение бустинга — в `../solution/pipeline.ipynb`; сюда скопированы только его веса.

## Инференс

```
python inference_new.py --data-dir /путь/к/test --output submission.csv
```

| аргумент | что | по умолчанию |
|---|---|---|
| `--data-dir` | каталог теста: внутри `bs/` и `sample_submission.csv` | обязателен |
| `--output` | куда писать сабмит | `submission.csv` |
| `--models` | веса бустинга | `models/` |
| `--unet` | веса U-Net | `models/unet_full_ep25.pt` |
| `--norm` | нормировка каналов U-Net | `models/unet_norm.json` |
| `--unet-weight` | вес U-Net в смеси | 0.45 |
| `--threshold` | порог смеси | 0.4 |
| `--work` | временный кэш признаков теста, ~1.9 ГБ | `work/` |

Время: **108 с на 89 тестовых чипов** на RTX 2050 — признаки 24 с, бустинг 60 с, U-Net 23 с.

### Что делает `inference_new.py`, по шагам

1. **Кандидаты и степень.** Для каждого тестового чипа: NBR до и после по сглаженным
   окном 3×3 каналам B8A/B12, dNBR, пороги организаторов по типу покрова →
   степень 0–3. Кандидат — пиксель со степенью ≥ 1.
2. **Признаки бустинга** — 60 чисел на кандидата: каналы, индексы, радар, рельеф,
   покров, облака, оконные статистики. Сохраняются в `work/`.
3. **Бустинг, первый проход** — 5 моделей XGBoost (`pass1_fold0..4.ubj`),
   вероятности усредняются.
4. **Бустинг, второй проход** — контекст из карты вероятностей первого прохода
   (средние по окнам, размер связных пятен) + признаки → `pass2.ubj`.
5. **U-Net** — для каждого чипа 40-канальный тензор 512×512, нормировка из
   `unet_norm.json`, предсказание с TTA: исходный снимок + два отражения,
   вероятности усредняются. Берутся значения в точках кандидатов.
6. **Смесь:** `p = 0.45 · p_unet + 0.55 · p_бустинг`.
7. **Ответ:** кандидат с `p ≥ 0.4` получает степень по формуле, остальное — 0.
   Три маски на чип → три строки RLE. Проверки: состав `(chip_id, class_id)`
   совпадает с шаблоном, NaN нет.

Модели загружаются с `device="cuda"`. Инференс побитово детерминирован: сабмит,
выданный этим скриптом с нуля, сверен с отправленным на лидерборд — все 267 строк
совпадают.

## `unet_train.ipynb` — ячейки

### Ячейка 0 — конфигурация

Импорты; `SEED = 42` для `random`, `numpy`, `torch`, `PYTHONHASHSEED`. Пути: данные
`../../BS/bs`, веса в `weights/`.

| константа | значение |
|---|---|
| `CROP`, `CROPS_PER_CHIP`, `BATCH` | 256, 4, 8 |
| `EPOCH_SCHEDULE`, `EPOCH_STOP` | 60, 25 |
| `LR`, `WEIGHT_DECAY` | 1e-3, 1e-4 |
| `CKPT_EVERY` | 5 |
| `DNBR_THRESH` | пороги dNBR организаторов по типам покрова |

### Ячейка 1 — данные → тензоры

`chip_tensor` собирает для каждого из 224 чипов **40 каналов 512×512**:

| каналы | состав |
|---|---|
| 18 | 9 каналов Sentinel-2 до и 9 после (B2–B7, B8A, B11, B12), отражение в долях |
| 6 | dNBR, dNDVI, dNBR2, NBR до, NBR после, dMIRBI |
| 2 | отступ dNBR от первого порога своего покрова; степень по формуле |
| 6 | Sentinel-1: VV и VH до, после, разности |
| 2 | высота, уклон |
| 5 | тип покрова one-hot: лес, травы, пашня, пойма, прочее |
| 1 | облака и тени по SCL снимка «после» |

Метка — бинарная маска гари: классы 1–3 → 1. Тензоры в памяти в float16, 4.7 ГБ.

### Ячейка 2 — нормировка

Среднее и СКО каждого канала по каждому 8-му пикселю всех чипов →
`weights/norm.json`. Инференс нормирует тест теми же числами.

### Ячейка 3 — подача данных

- `producer` — за эпоху с каждого чипа 4 случайных кропа 256×256, поворот на
  0/90/180/270°, отражение с вероятностью 0.5;
- `batches` — `producer` в фоновом потоке, батчи готовятся заранее;
- `loss_fn` — BCE + Dice.

### Ячейка 4 — обучение

`smp.Unet("resnet34", encoder_weights="imagenet", in_channels=40, classes=1)`,
AdamW, OneCycle на 60 эпох (разгон первые 10 %), fp16 со скалированием
градиентов, **остановка на 25-й эпохе**. После каждой эпохи — loss и скорость
обучения; чекпоинт `unet_epN.pt` каждые 5 эпох.

~49 с на эпоху на RTX 2050, всего ~22 минуты.

### Ячейка 5 — сохранение

`weights/unet_final.pt` — веса; `weights/train_config.json` — архитектура,
гиперпараметры, история loss.

Для инференса веса кладутся в `models/unet_full_ep25.pt`, нормировка — в
`models/unet_norm.json`.
