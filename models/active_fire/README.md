# Модуль AF — активное горение

Попиксельная бинарная классификация снимков VIIRS: для каждого пикселя чипа
256×256 решается, есть ли в нём природное горение. Техногенные термоаномалии —
факелы и промышленные площадки — должны быть отнесены к фону.

**Результат: `F1_af = 0.9345`** на пятифолдовой перекрёстной проверке с
блокировкой по территории.

## Состав

| Путь | Назначение |
|---|---|
| `features.py` | Чтение каналов чипа и расчёт 38 признаков. Единственное описание состава признаков, используется и при расчёте таблицы предсказаний, и веб-приложением |
| `predict.py` | Применение модели к одному чипу: `load_model`, `predict_proba`, `predict_af`, проверка выходной матрицы |
| `inference.py` | Расчёт таблицы предсказаний по всем чипам шаблона, запись `results/af_submission.csv` |
| `artifacts/model.pkl` | Модель, порог вероятности, порядок признаков, размеры окон, начальное значение генератора |
| `artifacts/manifest.json` | Паспорт: гиперпараметры, метрики, контрольные суммы, что проверено |
| `artifacts/legacy/` | Предыдущее решение на детекции YOLO11n, заменено |
| `data/firms/` | Архивы NASA FIRMS за 2019–2025 годы, сжатые gzip. Нужны только при обучении |
| `notebooks/pipeline.ipynb` | Обучение и проверка качества, пять ячеек |
| `docs/REPORT.md` | Отчёт об экспериментах: проверенные и отвергнутые гипотезы |
| `docs/PIPELINE.md`, `docs/DESCRIPTION.md` | Построчное и содержательное описание тетради |
| `results/af_submission.csv` | Таблица предсказаний: 180 строк, 131 непустая матрица, 3877 пикселей горения |

## Применение

```python
from models.active_fire import WEIGHTS, load_model, predict_af

model = load_model(WEIGHTS)
mask = predict_af(path_to_chip, model)   # uint8, (256, 256), значения 0 и 1
```

Путь к чипу задаётся тремя способами: каталог с одной парой файлов VIIRS и AUX,
префикс `<каталог>/<chip_id>` или корень с подкаталогами `viirs/` и `aux/`.

Расчёт по всем тестовым чипам:

```powershell
.venv-af\Scripts\python.exe -m models.active_fire.inference --data-dir <каталог теста>
```

Ожидаемая структура каталога теста: `sample_submission.csv` и `af/viirs`,
`af/aux` с файлами `<chip_id>_VIIRS_I1-I5.tif` и `<chip_id>_AUX.tif`.
Скорость — около 0.75 секунды на чип на одном ядре, то есть примерно две с
половиной минуты на 180 тестовых чипов. Таблица проверяется по правилам
конкурса до записи.

### Особенность Windows

В Windows `AUX` — зарезервированное имя устройства, поэтому каталог `af/aux`
из структуры конкурсных данных там создать невозможно: распаковка завершится
ошибкой либо каталог будет переименован. Сами файлы `<chip_id>_AUX.tif`
допустимы, ограничение касается только имени каталога.

Поэтому адаптер принимает и раскладку без подкаталогов: оба файла чипа лежат
рядом в одном каталоге. Варианты для запуска в Windows:

- положить `<chip_id>_VIIRS_I1-I5.tif` и `<chip_id>_AUX.tif` в один каталог и
  указать его через `--data-dir`;
- переименовать каталог при распаковке, например в `aux_data`, и разложить
  файлы попарно;
- выполнять расчёт в подсистеме Linux, где ограничение отсутствует.

## Признаки

38 значений на пиксель:

| Группа | Состав | Обоснование |
|---|---|---|
| Исходные каналы | I1–I5, углы Солнца и сенсора, достоверность, тип покрова, высота, температура, влажность, ветер | все 13 слоёв чипа |
| Разности | `I4 − I5`, `I4 / I5`, `I3 − I2` | очаг 600–1200 K смещает максимум излучения в средний инфракрасный диапазон, поэтому в канале I4 контраст к фону на два порядка выше, чем в тепловом I5 |
| Контекстные, окна 5, 11, 21 | для `I4` и `I4 − I5`: отклонение от локального среднего, нормированное отклонение, локальное среднеквадратичное отклонение | пиксель горяч не абсолютно, а относительно окружения: степь в полдень раскалена сама по себе |
| Морфологические | разрыв до локального максимума, минимум, медиана | края очага |

Каналы читаются по текстовым описаниям GeoTIFF, а не по порядковому номеру:
в выданных данных имена файлов не соответствуют числу каналов внутри —
файл `*_VIIRS_I1-I5.tif` содержит восемь каналов, `*_AUX.tif` — пять.

## Внешние данные

Постановка требует отделять газовые факелы от пожаров. По одиночному снимку это
невозможно: факел действительно горит. Отличает его повторяемость — срабатывания
в одной точке из года в год, включая зиму, когда степь не горит. В выданных
данных зимы нет: все 420 обучающих чипов сняты с апреля по октябрь.

Архивы NASA FIRMS за 2019–2025 годы (1.44 млн детекций, после удаления
повторов 1.22 млн) дают карту постоянных термоаномалий. Пиксель считается
кандидатом в факелы, если зимние срабатывания фиксировались не менее чем в трёх
разных годах. Таких пикселей 24 361.

Диагноз подтвердился: 11.7 % ложных срабатываний базовой модели приходится на
0.09 % площади, занятой кандидатами в факелы — обогащение в 134.7 раза.

Эти пиксели подаются в обучение как трудные негативы с повышенным весом, и
модель учится отбивать их по самим каналам чипа. Прирост `F1_af` составил
0.0058. При расчёте предсказаний внешние данные не нужны: геопривязка тестовых
чипов скрыта правилами, и координат на входе нет.

## Что проверено

- Порядок признаков, рассчитываемых `features.py`, совпадает с сохранённым в
  модели при обучении — сверка выполняется при каждом применении.
- Модель загружается, полное применение к синтетическому чипу VIIRS возвращает
  бинарную матрицу 256×256 типа uint8.
- Таблица предсказаний прошла проверку по правилам конкурса: 180 уникальных
  строк, 131 непустая матрица, 3877 положительных пикселей, нарушений формата
  и кодирования нет.

Обучение независимо не воспроизводилось: обучающие данные в репозиторий не
входят. Приведённые метрики взяты из отчёта автора модели.

## Ограничения

1. Карты факелов при расчёте предсказаний нет и быть не может: геопривязка
   тестовых чипов скрыта. Модель отбивает их только по содержимому снимка.
2. Оценка на перекрёстной проверке слегка оптимистична: сцены между фолдами
   пересекаются. На строгом разведении территории и времени, где в обучении
   остаётся 27 чипов из 420, результат составляет 0.8323.
3. Модель не насыщена данными: разрыв между 336 и 27 обучающими чипами
   составляет 0.10 по `F1_af`. Основной резерв — расширение выборки.
4. Порог вероятности общий для дневных и ночных пролётов.

## Предыдущее решение

В `artifacts/legacy/` лежит первая версия — детекция YOLO11n с `F1_af = 0.4176`.
Заменена по двум причинам. Во-первых, объекты в данных крайне мелкие: медианный
размер связной компоненты — 2 пикселя, 41 % компонент занимают ровно один
пиксель. Прямоугольник вокруг диагональной цепочки из трёх пикселей неизбежно
захватывает шесть фоновых, поэтому потолок любого детектора на этой задаче —
`F1_af = 0.789`, что показано расчётом по идеальной разметке. Во-вторых, простое
пороговое правило `I4 > 330 K` без всякого обучения даёт 0.8512, то есть
превосходит и обученный детектор, и его теоретический потолок. Это указывает,
что эталонная разметка построена пороговым алгоритмом по тем же каналам, и
задача сводится к попиксельной классификации, а не к поиску объектов.
