# `pipeline.ipynb` — описание ячеек

5 кодовых ячеек, выполняются по порядку.

| файл | что |
|---|---|
| `pipeline.ipynb` | пайплайн |
| `submission.csv` | ответ: 180 строк, маски в RLE |
| `model.pkl` | обученная модель, порог, список признаков |
| `requirements.txt` | зависимости |
| `REPORT.md` | отчёт об экспериментах |

---

## Ячейка 0 — конфигурация

Импорты, фиксация случайности: `SEED = 42` в `random.seed`, `np.random.seed`,
`PYTHONHASHSEED`.

| константа | значение | назначение |
|---|---|---|
| `PROJECT` | `../..` | корень проекта относительно ноутбука |
| `ROOT` | `PROJECT/af` | обучающая часть |
| `TEST` | `PROJECT/fire-test-renamed/test` | тестовая часть |
| `FIRMS_DIR` | `PROJECT/ADDITIONAL_DATA` | архивы FIRMS |
| `WINS` | `(5, 11, 21)` | окна контекстных признаков |
| `NEG_PER_CHIP` | `1500` | негативных пикселей с чипа |
| `FLARE_SHARE` | `0.30` | доля кандидатов в факелы среди негативов |
| `FLARE_WEIGHT` | `10.0` | вес факельных негативов |
| `N_FOLDS` | `5` | фолдов кросс-валидации |
| `GSD`, `SIZE` | `375.0`, `256` | размер пикселя в метрах, сторона чипа |
| `THRESHOLDS` | `[0.9 … 0.9999]` | сетка порогов вероятности |
| `PARAMS` | dict | гиперпараметры `LGBMClassifier` |
| `CHANNELS` | 13 имён | каналы из GeoTIFF |

Читается `af/meta.csv`, добавляется колонка `tile = (epsg, x_min, y_min)`,
формируется список `IDS` из 420 чипов.

**Вывод:** `чипов: 420 | seed: 42`

## Ячейка 1 — признаки

`window_stats(a, w)` — локальное среднее и СКО в окне `w` через `uniform_filter`
от `a` и `a²`.

`pixel_features(channels)` — словарь каналов → матрица «пиксели × 38» и имена.
NaN заменяются нулями.

| индексы | состав |
|---|---|
| 0–12 | сырые каналы из `CHANNELS` |
| 13–15 | `I4 − I5`, `I4 / I5`, `I3 − I2` |
| 16–33 | для окон 5/11/21 и баз `I4`, `I4 − I5`: отклонение от среднего, z-оценка, СКО |
| 34–37 | разрыв до локального максимума `I4 − I5` и `I4`, минимум `I4` 3×3, медиана `I4` 5×5 |

`read_channels(chip_id, root)` — читает VIIRS- и AUX-файлы чипа в один словарь,
имена каналов берёт из `src.descriptions`.

`read_mask(chip_id)` — эталонная маска как плоский булев массив.

Заполняются `FEATURES`, `TARGETS`, `NAMES`.

**Вывод:** `признаков: 38 | горящих пикселей: 9725`

## Ячейка 2 — карта факелов из FIRMS

Все CSV из `ADDITIONAL_DATA/*/fire_archive_*.csv` склеиваются, дубли по
`(latitude, longitude, acq_date, acq_time, satellite)` удаляются.

Для каждой детекции: признак «зима» (месяцы 12, 1, 2) и год. Координаты
переводятся из EPSG:4326 в обе зоны UTM (32637, 32638) один раз.

Цикл по чипам: детекции переводятся в индексы пикселей чипа
`col = (x − x_min) / 375`, `row = (y_max − y) / 375`, отбрасываются вне 256×256.
`bincount` считает зимние детекции на пиксель и число лет с детекциями.

`FLARES[chip_id]` — булева маска: зимних детекций ≥ 1 и лет ≥ 3.

Координаты используются только здесь, при обучении. На тесте эта ячейка
не нужна.

**Вывод:**
```
детекций FIRMS: 1218415 | зимних: 36439
пикселей-кандидатов в факелы: 24361
```

## Ячейка 3 — кросс-валидация и порог

Фолды: уникальные тайлы перемешиваются `RandomState(SEED)` и режутся `[i::5]`.

`training_set(chip_ids)` — для каждого чипа все горящие пиксели, 30 % негативов из
факельной маски `FLARES` и остальные 70 % из прочего фона. Факельным негативам
выставляется вес `FLARE_WEIGHT`. Возвращает `(X, y, w)`.

Цикл по 5 фолдам: `LGBMClassifier(**PARAMS)` обучается с `sample_weight` на тайлах
вне фолда, предсказывает на тайлах внутри; вероятности пишутся в массив `oof`.

Для каждого порога из `THRESHOLDS` — `precision_score`, `recall_score`,
`f1_score` по пулу пикселей (`average="binary"`). Лучший порог → `THRESHOLD`.

**Вывод:**
```
 threshold  precision  recall     f1
    0.9000     0.8636  0.9900 0.9225
    0.9900     0.8926  0.9758 0.9324
    0.9950     0.9032  0.9681 0.9345
    0.9990     0.9216  0.9342 0.9278
    0.9995     0.9313  0.9147 0.9229
    0.9999     0.9498  0.8461 0.8949

порог 0.995 -> F1 = 0.9345
```

## Ячейка 4 — финальная модель и submission

`rle_encode(mask)` — маска в строку RLE: C-order, нумерация с 1, пары «старт длина».
`rle_decode(text)` — обратно. Ассерт: round-trip на всех 420 эталонных масках.

Финальная модель обучается на всех 420 чипах той же `training_set`, сохраняется
в `model.pkl` рядом с ноутбуком (ключи `model`, `threshold`, `features`, `windows`, `seed`).

Список AF-чипов — из `sample_submission.csv` по префиксу `AF_`. Для каждого:
`read_channels(root=TEST/"af")` → `pixel_features` → `predict_proba ≥ THRESHOLD` →
`reshape(256, 256)` → `rle_encode`.

Ассерты: нет NaN, набор `chip_id` совпадает с шаблоном. Запись в
`submission.csv` рядом с ноутбуком.

**Вывод:**
```
submission.csv: 180 строк, непустых 131
пикселей горения: 3877 (22 на чип)
```
