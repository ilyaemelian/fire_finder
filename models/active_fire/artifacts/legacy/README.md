# Предыдущее решение модуля AF

Детекция YOLO11n, `F1_af = 0.4176`. Заменена попиксельным классификатором
LightGBM с результатом 0.9345.

Причины замены изложены в `models/active_fire/README.md` и подробно в
`models/active_fire/docs/REPORT.md`. Кратко: медианный размер связной компоненты
в данных равен двум пикселям, 41 % компонент занимают ровно один пиксель, поэтому
прямоугольник вокруг цели неизбежно захватывает фон. Расчёт по идеальной разметке
даёт потолок любого детектора `F1_af = 0.789`, тогда как пороговое правило
`I4 > 330 K` без обучения даёт 0.8512.

Материалы сохранены для истории и в расчёте предсказаний не участвуют:
весовые коэффициенты `best.pt`, журнал обучения `results_yolo.csv`, тетрадь
`baseline_yolo.ipynb`, описание решения `STRUCTURE_YOLO.md` и полученная тогда
таблица предсказаний `active_fire_yolo.csv` (180 строк, 120 непустых матриц,
9246 пикселей).
